# Codex Project Rules

Use `PROJECT_RULES.md` as the source of truth for engineering direction.

When working in this repository:

- Implement features in small phases that match `TASKS.md`.
- Keep route handlers thin and move business logic into services.
- Add or update tests with each meaningful behavior change.
- Keep AI responses grounded in retrieved knowledge-base context.
- Prefer explicit escalation over confident hallucination.
- Update documentation when setup commands, architecture, or behavior changes.
