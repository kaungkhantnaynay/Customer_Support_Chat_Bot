# Security Policy

Do not report vulnerabilities through public issues. Use GitHub's private security
advisory feature and include reproduction steps, impact, and the affected configuration.

Never include API keys, passwords, conversation tokens, real customer messages, or
database contents in a report. Rotate any credential that may have been exposed before
sharing diagnostic details.

This repository is a portfolio and preview implementation unless a release is
explicitly marked production-ready. It is not a PII-redaction or regulated-data system.
