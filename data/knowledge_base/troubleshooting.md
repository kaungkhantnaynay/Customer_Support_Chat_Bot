# Troubleshooting Guide

If the app is slow, customers should refresh the page and check their internet connection.

If login fails, customers should confirm that they are using the correct email address and then try a password reset.

If the dashboard does not load, customers should clear their browser cache or try a private browsing window.

If a bug blocks the customer from using a paid feature, support should create a technical support ticket.

Support should ask for the customer's browser, device, and a short description of the issue before escalating technical problems.
