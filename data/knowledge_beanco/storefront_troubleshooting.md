# BeanCo Storefront Troubleshooting

If the storefront is slow or a page does not load, refresh the page and check the internet connection. If the problem continues, try a private browsing window and include the browser, device, page, and a short description when contacting support.

If checkout reports that a product is unavailable, return to the cart because stock and pricing are revalidated before an order is placed.

If secure payment does not open, retry from the awaiting-payment order page. Never paste payment credentials, passwords, verification links, reset links, or session cookies into support chat.

Support should create a technical support ticket when a repeatable bug prevents checkout, account access, payment, or order review.
