# Skills This Project Should Demonstrate

## Python Backend Engineering

- FastAPI application structure
- Pydantic validation
- SQLAlchemy persistence
- Dependency injection
- Async service design
- Testing with pytest

## AI Engineering

- Retrieval-Augmented Generation
- Embeddings and vector search
- Prompt design for grounded answers
- Tool-style actions such as ticket creation
- Conversation memory
- Evaluation datasets and metrics

## Product Engineering

- Escalation rules
- Admin analytics
- Feedback loops
- Source citations
- Clear operational limits

## Portfolio Story

The final project should show that this is not just a chatbot demo. It should read as a small customer support platform with realistic engineering choices, measurable quality, and a polished user experience.
